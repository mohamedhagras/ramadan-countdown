# باقي على رمضان 🌙

صفحة عدّ تنازلي لرمضان (ميلادي + هجري) مع مواقيت الصلاة بتوقيت القاهرة، وآية/دعاء اليوم، ووضع داكن، ومشاركة كصورة.

ملف واحد فقط: `index.html` (بدون أي مكتبات أو بناء).

## النشر على GitHub Pages
1. ارفع `index.html` و`README.md` على ريبو جديد.
2. من **Settings → Pages**: اختار Branch `main` والمجلد `/ (root)` ثم Save.
3. الرابط هيظهر بعد دقيقة تقريبًا: `https://USERNAME.github.io/REPO/`

## تعديل التواريخ
التواريخ المتوقعة في مصفوفة `EVENTS` داخل `index.html`. عدّل التاريخ لو الإعلان الرسمي اختلف.

## تجربة وضع الإفطار
ضيف `#iftar` في آخر الرابط.
